# Env-gui Application

## Project Description

A Qt application that allows users to define evironment variables, select an executable, and launch it in a customized enviroment.
## Installation 

Step-by-step instructions on how to install and setup this project locally.

- Open Qt creator, if not installed go here: https://www.qt.io/development/download-qt-installer-oss
- Open file then select the CMakelist.txt in the env-gui folder
- Click import
## Usage
- select an executable by pressing the "**select executable**" button
- click on a valid executable
- click the "**Add**" button then input a key and a value in their respective boxes then click "**Ok**"
- If you want to remove a variable click "**Remove**" then input the row you want to remove
- Once ready click "**Run**"
